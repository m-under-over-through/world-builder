# Screen map

Every screen and state of the client, with the error codes it can show. The UI builder builds this; it does not invent screens. Copy comes from `workshops/<slug>/copy.md`.

All routes live under `/<slug>/`. Storage on the device is namespaced by slug.

The top bar is the app's name and the organizer, two centered lines on a phone and a block on the left on a laptop, where it also carries the progress strip and "n of M answered" while a session runs; nothing else (ADR 0015). The foot of every screen is one small link, "About this app", to the one page that explains the app, shows the facts, and deletes everything (ADR 0013); on a phone's card screen the pill "Your world so far" sits above it. That page and the two texts have their own foot.

The look is the design's, "index cards on a dotted desk" (`design/DESIGN.md`): the tokens are custom properties in `apps/web/src/app.css`, the two typefaces are served from this origin.

## Offline and failure behaviour

- No network: everything works; events wait in the outbox; the card shows "Saved on this device". The join itself can be queued.
- After a server restore: the device keeps accepted events for fourteen days; on open it compares them with `GET /me` and re-sends any the server lacks, silently.
- `AUTH_CODE_UNKNOWN` on a stored code (the participant was deleted, or the workshop was reset): clear the stored code and show Welcome with one calm line that says the link this phone remembered is not in use any more, and to open the link from the email again. With a link's value, the same code is made again on that open and joins as a new participant ("Opening your link again starts you over from nothing", on the about page's delete line).
- `WORKSHOP_CLOSED`: a closing screen, with the page about the app at its foot as on every screen; no new events are created.
- `CLIENT_STORAGE_UNAVAILABLE`: the app still runs in memory, round after round, for as long as the tab stays open; it warns that nothing is kept, and that opening the link from the email again continues later.
