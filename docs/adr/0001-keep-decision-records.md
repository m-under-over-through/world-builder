# 0001. Keep decision records

Date: 2026-10-23. Status: accepted.

## Context

The operator must be able to explain every component and every choice, including months later and to the partner. Choices made in conversation evaporate.

## Decision

Every decision not already spelled out in the architecture plan gets a short numbered file here before the code that depends on it lands. Format: context, decision, consequences, alternatives.

## Consequences

A little writing per decision. In exchange, "why is it like this" always has an answer that is a file, not a memory.
